What is HTML5?

The fifth and latest major version of the Hypertext Markup Language (HTML5), the standard code used to structure and present content on the World Wide Web.

HTML stands for HyperText Markup Language. It was first created in the early 1990s by Tim Berners-Lee, the same person who invented the World Wide Web in 1989.

But unlike Palm Pilots, car phones and other breakthrough products of the 90s, HTML is still in use today.

Key Features of HTML5:

  • Improved semantic elements
  • Enhanced multimedia support
  • Native API support
  • Offline and storage capabilities
